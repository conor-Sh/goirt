# Research sources

These files are the evidence base for Goirt v1. They are copied verbatim from the
firstmate research runs and are kept as written; later documents refer to them rather
than rewriting them.

| File | Source | Date |
|---|---|---|
| `port-spec.md` | `goirt-port-spec` research report, firstmate project data | 2026-10-27 |
| `lpis-data.md` | `goirt-lpis-data` research report, firstmate project data | 2026-10-27 |
| `crops-2025.tsv` | DAFM 2025 LPIS agricultural crop tally generated by `goirt-lpis-data` | 2026-10-27 |

The crop tally was generated from the full 2025 LPIS GeoPackage (176 crop values).
`lpis-data.md` stopped early, so section 7 lists checks completed later in the build;
`docs/DATA.md` records the 2025 outcomes.
